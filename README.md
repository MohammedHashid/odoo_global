# Odoo Global — Official Website

This repository contains the source code for the official Odoo Global website.

The project is a static website built using HTML, CSS, JavaScript, and a PHP-based contact form handler.

---

## Overview

Odoo Global provides ERP implementation, customization, and consulting services based on Odoo.

This repository includes:

- Responsive website pages
- Organized asset structure (CSS, JS, Images, Fonts)
- PHP contact form backend (sendemail.php)

---

## Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP

---

├── index.html

---

## Local Development

This project can be developed using:

- VS Code with Live Server  
- XAMPP / WAMP (for PHP support)  
- Any Apache/Nginx + PHP setup  

Note: The contact form requires a PHP-enabled server environment.
